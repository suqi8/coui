# COUI Canvas 画布

COUI Canvas 是一个在浏览器里用 COUI 真组件拼 ColorOS 17 界面的草图工具。把组件摆到手机或宽屏屏幕上，把屏幕连起来点一点走完流程，然后把设计作为提示词交给 AI 编程工具，或者直接拿走它生成的 Kotlin 代码。它完全在浏览器中运行：无需账号、无需服务器，什么都不会上传。

<a href="/coui/canvas/" target="_blank">打开 COUI Canvas</a>

## 使用方式

1. **拼装**：点击组件面板里的组件，添加到当前屏幕；也可以直接拖到画布上。组件会吸附 4dp 网格、16dp 屏幕边距和彼此的边缘。把设置行贴到另一组设置行上，它们会合并成一个 `Card` + `CardListGroup`；并排的按钮和标签片会合成一行。**整理**会把各种栏贴到边缘，其余内容按 COUI 的方式依次排好。
2. **连接与预览**：在属性面板里给设置行、按钮、标签或对话框按钮设置目标屏幕（或「返回上一页」）和过渡动画。**预览**会带着 COUI 页面转场把流程放一遍；开关能拨、滑块能拖、对话框能关。
3. **交出去**：
   - **提示词**：整个应用（或单个屏幕）写成中文或英文的实现说明，每个部件都写明对应的 COUI 组件，并让工具按 [`coui-app` 技能](./ai) 来实现。
   - **Kotlin 代码**：每个屏幕一个页面（基于技能里的 `CouiPage` 脚手架），加上 `coui-nav` 导航、主题和 `strings` 资源。
   - **分享链接**：设计压缩后放在地址里（`#docz=`），打开链接就能打开这份设计。

## 组件

| 分类 | 组件 |
| --- | --- |
| 栏 | 顶栏（大标题、设置首页带搜索、小标题）、搜索框、标签栏、悬浮底部导航 |
| 列表 | 分类标题，以及开关、箭头、操作、下拉、复选、单选、勾选、滑块、输入等设置行 |
| 按钮 | 按钮（主要、次要）、图标按钮、悬浮按钮、标签片 |
| 内容 | 卡片、文字、图片占位、顶部提示、空状态、输入框、滑块、进度、分割线 |
| 弹层 | 带 COUI 17 按钮栏的对话框、底部面板、消息条 |

每个组件都由组件库本身绘制，并使用设计的主题（浅色或深色、任意主题色），所以画出来的样子就是代码运行出来的样子。

## 让 AI 代理画草图

**分享与文件 → 复制给 AI 代理的指令** 会复制一段给 Claude Code、Codex 等能读网页的代理的说明。代理会阅读 [`agent.md`](/coui/canvas/agent.md)，写出设计文档，并回复一个链接；打开链接，草图就出现在你的画布上，改好之后再生成提示词或代码。

## 文件

**保存项目** 会把设计存成 `.json` 文件；**打开项目** 可以再读回来，包括 AI 代理写的文档。画布还会把当前设计保存在浏览器里，下次打开还在。

## 键盘

| 按键 | 操作 |
| --- | --- |
| 滚轮、`Ctrl` + 滚轮 | 平移、缩放 |
| 在空白处拖动 | 平移 |
| `Ctrl` + `+` / `-` / `0` | 放大、缩小、适应窗口 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 撤销 / 重做 |
| `Ctrl+D` | 复制一份 |
| 方向键（`Shift` = 8dp） | 微移 |
| `Ctrl` + 拖动 | 不吸附地移动 |
| `Delete` | 删除组件或屏幕 |
| `T` | 整理 |
| `P` | 预览 |

## 本地运行

```bash
./gradlew :docs:canvas:wasmJsBrowserDevelopmentRun
```

文档站用的构建是 `./gradlew :docs:canvas:wasmJsBrowserDistribution`（产物在 `docs/canvas/build/dist/wasmJs/productionExecutable`）。
